Key finding: Exploration reward solves U-trap (0→100%) but breaks narrow door (100→0%). The reward encourages wide exploration, conflicting with the precise alignment needed for narrow passages. This exploration-exploitation dilemma is the core contribution — annealing (v7) aims to recover narrow-door performance while retaining U-trap escape ability.

Ablation summary

Curriculum alone: standard SR drops to 74%, narrow door collapses to 8%, U-trap stays 0% → curriculum is not the key.
Exploration reward is the decisive factor for U-trap escape, but introduces the narrow-door regression.
